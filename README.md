# VibeRadar

Проєкт аналізує активність появи нових вебсайтів та сервісів штучного інтелекту за даними відкритого каталогу FreeSerp.

## Що зроблено

1. Моніторинг активності. Головний екран показує кількість нових сайтів за останню добу, тиждень і місяць, а також векторний графік щоденної появи сайтів з підсвічуванням середнього рівня.
2. Порівняння платформ створення сайтів. Окремий розділ збирає показники чотирьох систем генерації коду: Lovable, v0, Bolt та Base44. Для кожної визначено загальну кількість сайтів, частку доменів з авторитетністю від одиниці та провідні тематичні напрямки.
3. Теплова карта ніш. Таблиця розподілу кількості проєктів за п'ятнадцятьма категоріями та чотирма платформами. При виборі клітинки відкривається список найпомітніших сайтів.
4. Пошук вільних ринкових ніш. Інструмент відбору напрямків, де присутня висока активність створення нових проєктів, але конкуренти мають низький рівень авторитетності домену.
5. Аудит технічного стану домену. Перевірка конкретної адреси за сімома правилами пошукової гігієни, включаючи код відповіді сервера, довжину заголовка та змістовність опису.
6. Опис методики. Розділ з роз'ясненням значень полів, правил підрахунку та обмежень швидкості запитів.
7. Надійний мережевий шар. Запити передаються через чергу з контролем частоти. Відповіді зберігаються у пам'яті поточної вкладки браузера, а при відсутності зв'язку інтерфейс автоматично підвантажує збережені резервні дані.

## Як запустити

1. Встановіть середовище Node.js на комп'ютер.
2. У папці проєкту запустіть команду:

```bash
node server.js
```

3. Відкрийте у браузері адресу:

```text
http://localhost:4000
```

Локальний сервер роздає файли та водночас передає запити до джерела даних, оминаючи мережеві обмеження браузера. Якщо потрібна сторінка перевірки роботи мережевих методів, відкрийте адресу:

```text
http://localhost:4000/tests.html
```
або через версель: https://serp-intel-ebon.vercel.app/index.html
## Що не встиг

1. Збереження вибору користувача в адресному рядку браузера. Налаштовані фільтри у таблицях скидаються при переході між вкладками, тому не можна передати колезі пряме посилання на обрану нішу.
2. Завантаження знайдених списків сайтів у табличні формати CSV або Excel.
3. Графік зміни часток платформ у часі за останній місяць.

## Що доробив би далі

1. Додав би підтримку адресних параметрів сторінки, щоб будь-який набір фільтрів чи перевірений домен зберігалися у посиланні.
2. Додав би кнопку вивантаження таблиць у файл для подальшої обробки у зовнішніх програмах.
3. Створив би порівняльний графік щоденного приросту кожної платформи розробки окремо.
4. Додав би сповіщення про різку появу нових проєктів у конкретній ніші.
