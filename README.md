# ⚡ VibeRadar

**VibeRadar** — аналітичний веб-інструмент для дослідження екосистеми вебсайтів, створених AI-білдерами (**Lovable**, **v0 by Vercel**, **Bolt.new**, **Base44**), на базі публічного безключового API [FreeSerp.ai](https://freeserp.ai) (`index=sites`).

> 🚀 **Демонстрація**: Повністю статичний проєкт без етапу збірки, готовий до розгортання на **GitHub Pages** або локального перегляду в будь-якому сучасному браузері.

---

## 📌 Що реалізовано

| Сторінка / Модуль | Опис та можливості |
| :--- | :--- |
| **⚡ Pulse (`index.html`)** | Загальний зріз індексу: нові сайти за сьогодні, вчора, 7 та 30 днів; AI-стартапи; чистий інтерактивний **SVG-графік** щоденної динаміки за останні 30 днів із тултіпами та лінією середнього; рейтинг топ-ніш та стеків. **Під кожною цифрою дрібним текстом вказано джерело запиту**. |
| **🛠 Builders (`builders.html`)** | Порівняння 4 білдерів (Lovable, v0, Bolt, Base44): загальна кількість проєктів (`total`), частка сайтів з Domain Rating &ge; 1 (`dr_min=1`), топ-3 профільні ніші за викликами `countBy`. Асинхронне поступове заповнення карток із ізольованою обробкою помилок та модальне вікно топ-5 за DR. |
| **🗺 Niche Map (`niche-map.html`)** | Теплова карта 4 білдери &times; 15 ніш. Кожна клітинка показує реальний `total` із `size=1`. Покрокове заповнення із живим прогрес-баром, колірною легендою та обов'язковим **застереженням, що це кількість сайтів, а не їхня якість**. Клік по клітинці відкриває топ-5 сайтів за авторитетністю DR. |
| **🔍 Gap Finder (`gap-finder.html`)** | Інструмент виявлення ринкових можливостей («блакитних океанів»): фільтрація за нішами, максимальним DR конкурентів та білдером. Розрахунок індексу можливостей (Opportunity Score) та лістинг слабких сайтів. |
| **🔬 Teardown (`teardown.html`)** | Глибокий аудит технічного стану та SEO-гігієни домену. Критерії винесено в **окремий формалізований масив із 7 правил з детальними поясненнями**. Домен, якого немає в індексі, показується інформаційно як «Не знайдено в індексі», а не як помилка. |
| **📖 Method (`method.html`)** | Опис методології обробки даних, обмежень відкритого API, визначення Domain Rating та суворе застереження: **`went_live` — це дата першої фіксації доступності сайту зондом, а не офіційний реліз**. |
| **🧪 Data Layer & Tests (`js/api.js`, `tests.html`)** | Клієнт API з чергою (&le; 3 req/sec), кешуванням у `sessionStorage`, таймаутом 10 с, повтором при 502 та параметрами `agent=VibeRadar/1.0` і `project=VibeRadar`. Діагностична сторінка `tests.html` перевіряє методи на живому API. |
| **🎨 Спільні стилі (`css/style.css`, `js/ui.js`)** | Чистий ванільний CSS із підтримкою світлої/темної теми через `prefers-color-scheme` та ручним перемикачем ☀️/🌙, адаптивною версткою для мобільних пристроїв та планшетів. |

## 🛠 Технологічний стек та обмеження

- **Чистий HTML5, CSS3, Vanilla JavaScript (ES Modules)**.
- **Жодних фреймворків** (без React, Vue, Vite, Webpack, Tailwind).
- **Жодної збірки**: файли відкриваються безпосередньо.
- **Без сторонніх бібліотек**: SVG-графіки, модальні вікна, прогрес-бари та черга написані вручну.
- **Безпечна робота з API**: усі виклики йдуть виключно через `js/api.js` з контролем частоти запитів.

## 🚀 Як запустити проєкт

### Варіант 1. Локальний запуск (найпростіший)
1. Відкрийте папку проєкту в провіднику.
2. Двічі клікніть на `index.html` або відкрийте файл у будь-якому сучасному веб-браузері (Chrome, Firefox, Safari, Edge).
   *(Примітка: для роботи ES-модулів у деяких суворих налаштуваннях браузерів рекомендовано локальний сервер)*.
3. Або запустіть найпростіший локальний сервер:
   ```bash
   # Через npx (Node.js):
   npx serve .

   # Або через Python:
   python -m http.server 8000
   ```
   Після цього відкрийте `http://localhost:8000/index.html`.

### Варіант 2. Запуск діагностичних тестів
Відкрийте у браузері файл `tests.html` (`http://localhost:8000/tests.html`).
Сторінка автоматично виконає 5 живих тестів проти `freeserp.ai/api.php` і продемонструє:
- Отримання статистики індексу (`getStats`).
- Швидкий підрахунок кількості (`countBy`).
- Пошук сайтів із пагінацією (`searchSites`).
- Миттєве завантаження з `sessionStorage` без мережевого запиту.

### Варіант 3. Розгортання на GitHub Pages
1. Створіть новий публічний репозиторій на GitHub.
2. Надішліть файли проєкту:
   ```bash
   git remote add origin https://github.com/ВАШ_АККАУНТ/VibeRadar.git
   git push -u origin master
   ```
3. У налаштуваннях репозиторію (**Settings &rarr; Pages**) оберіть гілку `master` та папку `/ (root)`.
4. Сайт стане доступним за адресою `https://ВАШ_АККАУНТ.github.io/VibeRadar/`.

## 📝 Що не встигли / Що доробили б за наявності додаткового часу

1. **Історичний тренд частки білдерів у динаміці**:
   - FreeSerp зберігає 30 днів півгодинних знімків у статистиці. Можна додати окремий графік співвідношення темпів зростання Lovable vs Base44 vs v0 за кожен день останнього місяця.
2. **Експорт вибірок у CSV / JSON**:
   - Додати кнопку завантаження списку доменів із `Gap Finder` та `Niche Map` для зручного подальшого аналізу в Excel чи базах даних.
3. **Deep-linking та спільний доступ через URL**:
   - Збереження стану фільтрів у `URLSearchParams` (наприклад, `gap-finder.html?niche=Code+%26+Dev+Tools&dr=10` або `teardown.html?domain=bolt.new`), щоб користувачі могли ділитися прямими посиланнями на результати аудиту.
4. **Мобільне меню-шторка (Burger Drawer)**:
   - Хоча поточне горизонтальне меню компактно загортається на мобільних пристроях, для екранів менше 360px класична шторка покращила б досвід взаємодії.
